# social-post — 訪談集的 FB 宣傳貼文

## 這是誰在說話（2026-07-29 修修裁決，最重要的一條）

**不是修修第一人稱，是他僱用的社群經理在寫。**

社群經理知道節目內容，**不知道修修的內心**。所以：

- 修修的私人經歷、當下感受、對內容的評價、他自己才知道的外部連結——**一律不寫**
- **不要留佔位符**。「這裡該有修修的反應」本身就是替他決定。機器不知道就
  **不寫那句**，他要加什麼是他自己的事
- 寫得出來的是：本集在講什麼、來賓是誰（憑逐字稿）、哪幾個點值得聽、懸念

第一版寫成了第一人稱（我身心不好、我是大粉絲、我現在坐捷運發呆），**整條路線
已作廢**，不要參考。

## 風格的單一事實來源

`data/brook/style-profiles-fable5/`，這個文類**跨三份側寫各取所需**：

| 層 | 來源 | 為什麼 |
|---|---|---|
| **視角與敘事** | `11-genre-people.md` §2 | 它就是第三人稱側寫——從 10 篇 podcast 人物文萃取，實測第三人稱佔 70–80%、「我」密度僅 2.5／千字 |
| **排版機械層** | `13-genre-social-post.md` §7 / §9 | 字數、段落、U+200B 分段、emoji、無 markdown、連結密度——這層跟人稱無關，FB 就是 FB |
| **禁區** | `20-negative-constraints.md` | 42 詞黑名單、誠信紅線 |
| **語彙** | `02-lexicon.md` | 簽名片語、句式模板 |

載入順序：`00 → 02 → 11 §2 → 13 §7/§9 → 20 → 30`。

⚠️ **`13-genre-social-post.md` 的 §1（九拍骨架）、§5（懸念）、§6（自我露出）
是從 5 篇第一人稱貼文萃取的，人稱改了之後大半失效**——「我」密度 17.3、夾心
結構、自我露出 df 5/5 全部不適用。只用它的 §7 §9（機械層）與 §4（專名密度）。

**「我」怎麼處理**：語料的第三人稱文仍有 2.5／千字的「我」（開場自報關係、
收尾感想）。但那是修修本人寫的；社群經理寫不出「我的偶像」。規則：**要用第一
人稱時一律用「我們」**（＝節目），例如「我們這集聊到」。單數「我」不出現。

本 skill **不重述側寫內容**，只規定流程。

## 流程

### 0. 前置檢查

`data/brook/style-profiles-fable5/` 的 `11-genre-people.md` 與
`13-genre-social-post.md` 都在。不在 → **停**，先補側寫，不要憑印象寫。

### 1. 素材與 brief

| 欄位 | 來源 | 缺了怎麼辦 |
|---|---|---|
| 逐字稿 | `<episode>/transcript_prose.md` | **停**——沒有逐字稿不要寫 |
| 來賓姓名 | 使用者給 | 停，不從逐字稿猜 |
| EP 編號 | 使用者給 | `EP??` |
| Podcast／YouTube 連結 | 使用者給 | `【連結待補】` |

`transcript_prose_suspect.json` 若存在先掃一眼——落在那些時段的話**不要拿來
當引言**（講者判定可疑）。

### 2. 素材編號清單

拆成編號清單，之後的覆蓋復查對著它：

1. **來賓金句候選**——逐字抄，含口語質地
2. **來賓履歷錨點**——校名／公司／年份／書名／獎項／數字。13 §4a 實測平均
   26.8 個／篇，這是可信度的來源
3. **會讓人「蛤？」一下的具體事實**——優先於四平八穩的論點摘要
   （修修 2026-07-29 補的例子：「他在新加坡的時候早晚各坐一小時冥想」）
4. **未被回答的大問題**——收尾要用（見第 4 步）

**⚠️ 模型知道這位來賓是誰。** 學經歷、著作、獎項、頭銜一律**只能來自逐字稿**，
維基百科等級的補充是誠信紅線（20-negative §4）。逐字稿沒講就**不寫那句**。

### 3. 結構（六拍）

第一版的九拍是第一人稱骨架，作廢。第三人稱促銷文用這六拍：

```
[1] 鉤子      節目裡最反直覺、而且對讀者有後果的一個事實。給結論，不是給預告
[2] 這集是誰   來賓是誰 + 這集在講什麼，壓縮在 1–2 段
[3] 履歷弧線   反差／低谷 → 轉折 → 成就。用專名堆可信度，不要形容詞
[4] 亮點       2–4 個具體的點，**每個都要真的給答案**
[5] 懸念收尾   **全篇只留這一個問題**，而且它要有後果。回收 [1] 或 [3] 的線
[6] CTA        連結 + 一句推薦，**不要在這裡窄化受眾**
```

**[1] 鉤子為什麼不能用來賓履歷開場**：第一人稱版的鉤子是修修自己的反應
（「這應該是我笑得最誇張的一場訪談」），人稱改成社群經理之後**那個鉤子就沒了**，
開頭只剩履歷可放——而冷讀者連續兩輪都在第 7–11 段（履歷區）流失。這不是喜好
問題，是人稱改變的必然結果：**社群經理只能用內容當鉤子**。挑的標準是
「跟讀者有關 ＋ 他不知道 ＋ 跟他原本以為的相反」。

**[4] 亮點一定要給答案，不可以每個都吊。** 冷讀者 2026-07-29 抓到第二版吊了
三次（該不該收走 3C、失智症切入的理由、自由意志），原話：

> 懸念要有效，前提是我相信你**願意給**，只是這一題留著。
> 給零次、留三題，那不叫懸念，那叫吝嗇。

規則：**全篇只準留一個未回答的問題，就是 [5]。** 其他亮點該給結論就給，
「老師在節目裡給了他的判斷」「理由是從失智症切進去的」這種半吊子句型禁用。

**[5] 懸念要挑「有後果」的題，不是挑最有份量的題。** 第二版把自由意志放壓軸，
冷讀者說「不管答案是有還是沒有，我明天早上還是要七點起床通勤」；真正想知道
答案的是「我到底該不該戒手機／該不該把 3C 從小孩手上收走」。判準：**讀者聽完
之後會不會做不一樣的事。**

**[5] 是這個文類存在的理由**（修修 2026-07-29：「我在 FB 宣傳 Podcast 的結尾，
一定會跟部落格不一樣，因為目的就是要留懸念」）。做法看他的實改：

> 訪談最後，我問老師一題書中只佔一點點篇幅，但其實貫穿了他這幾十年的問題：
> 「人到底有沒有自由意志？」
> 老師的回答相當精彩，也給了我很多啟發。

三個動作：**把問題升格**（「貫穿他這幾十年」）→ **問題單獨成段** → **答案留在
節目裡**。第一版把 Libet 實驗講完了，那等於讀者拿到答案就不用去聽。

**話題轉場要有一句「節目中我們問他 X」**（修修唯一留註解點名的一條：「要加入
這一句才有銜接啊」）。第一人稱版是「我問他」，第三人稱版用「我們」。作用不只
銜接——是把貼文錨回**這是一場訪談**，不是知識整理。

**不要把收穫講完。** 讀者拿到完整體驗就沒有理由點連結。

### 4. 寫 FB 版

機械層照 13 §7：**1,100 字 ±200、19–30 段、一段一句是預設、段間用單獨一行
U+200B（不是空行）、單段不超過 85 字、emoji 0 個、無 markdown、連結 ≤2 條**。

引言可做**最小順稿**（去贅詞、補主詞），不可改意思、不可換用詞。順過的引言
**不要包在「」裡**，改用不帶引號的轉述，並在交付時列出原話給修修覆核。

### 5. 機械 lint

```
python .claude/skills/social-post/scripts/social_lint.py <fb.md> --platform fb \
    --source <episode>/transcript_prose.md
```

**FAIL 一定要修掉再交。** WARN 逐條判斷。

### 6. 冷讀者驗收

2026-07-05 財富階梯 postmortem 的根因二：**review 方法認證了爛文案**。persona 太
聰明太買單、rubric 只要有行動就給分、judge 用分析師腦讀完全文，該給 20–30 的
給了 70–86。所以派 subagent 當冷讀者，規格寫死：

- **當純文字評**，不看排版不看配圖
- **滑手機腦**：一則 0.5 秒，逐段問「這跟我什麼關係／這什麼意思／所以呢」
- **回報流失點，不回報總分**——在第幾段決定不點開、為什麼
- 專門查：未定義的術語、沒動機的宣稱、不可信的誇大、跟 TA 無關的鉤子

冷讀者說「在第 N 段流失」→ 回第 3 步改結構，不是改字。

**三個一定要問的**（都是實際踩過的）：
- 有沒有哪裡是「吊胃口但沒給東西」，讓你覺得被耍？
- 結尾那個懸念，你會想知道答案還是覺得「那你倒是講啊」？
- 最後一句有沒有把你排除在外？

### 7. 交付

寫到 `<episode>/repurpose/fb.md`，並在 `<episode>/repurpose/.baseline/` 留一份
快照——**沒有快照就沒有回饋迴路**，修修改完之後 diff 不出紅線。

交付訊息列：素材覆蓋率、lint 結果、冷讀者的流失點、順過的引言清單、佔位符
（只有 EP 編號與連結兩種）。

## 原則

- **零 API 錢**：全程 subagent
- **具體 > 抽象**：專名密度是可信度來源；形容詞不是被禁是被上鎖（13 §4b：
  主力是「最」，每次後面跟一個可查證的名詞）
- **不編造**：逐字稿沒有的頭銜、研究、數字、外部概念連結，一律不寫；
  **不留佔位符**，不知道就是不寫那句
- 舊的 `agents/brook/fb_renderer.py` / `ig_renderer.py`（第一代，付費 API +
  先摘要再擴寫）已退役，不要呼叫
- IG carousel 文案不歸這裡（那是 ig-cards）；本 skill 只出 FB
