# Rubric: course-outline（課程產品／課綱／銷售頁）

單一 **0–10 購買（或滿意）意願分**＋質性回饋。實戰藍本：2026-07 課綱審稿（4/6/7 → 7/8/8.5）。

## 分數定義

| 分 | 意義 |
|----|------|
| 0–3 | 這不是給我的，關掉頁面 |
| 4–5 | 有興趣但疑慮壓過意願 |
| 6–7 | 想買但有明確卡點 |
| 8 | 會買，剩最後一哩 |
| 9–10 | 立刻買＋會推薦 |

## 質性回饋要求（每位 persona）

1. 第一眼印象＋分數＋理由。
2. 逐章重點反應（只挑有感的，標卡點與亮點，引小節編號）。
3. **五條最重要的疑慮或建議**——每條引小節編號＋原句。
4. 卻步點 1–3 個（即使高分也要）。
5. 一句話總結：要怎麼改你才會按下購買。

## 二輪加測

- 新分數對比前次＋變化主因。
- 前次疑慮逐條三態覆核（已解決／部分解決／未解決，引新版小節為證）。
- 若還不到 9 分：說出推到 9 分還缺的具體東西。
