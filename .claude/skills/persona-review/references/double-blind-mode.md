# 變體：雙盲歸納模式（v2，未實作）

不是審稿，是**歸納**：兩個 subagent 互不知情、各讀一組**不重疊**的樣本（先例：15/16 篇文章對半分），獨立歸納 pattern／方法論；兩邊都出現的 pattern＝真反射動作，只出現一邊的＝樣本雜訊或半成形習慣。

與主流程共用同一套骨架——平行盲測＋收斂＝可信度；差異只在：

- 輸入是「樣本集切兩半」而非「同一份文件」。
- 輸出是「pattern 清單＋兩邊命中對照」而非分數與 directives。
- 不需要 rubric，也不需要 persona（用同一個歸納 prompt、不同樣本）。

實戰範例：`E:\Projects\張修修的AI創作者新世紀\04_參考資源\修修文章方法論-雙盲歸納-2026-07-04.md`。

要實作時：加一個 `輪次＝雙盲歸納` branch，樣本切分寫進 Step 2、歸納 prompt 進 prompt-templates.md、對照表進 report-templates.md。
