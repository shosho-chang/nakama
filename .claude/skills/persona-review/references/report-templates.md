# 報告模板

黃金範例：`E:\Projects\張修修的AI創作者新世紀\01_課綱\TA審稿回饋-預錄課課綱-2026-07-03.md`（一輪）、同層 `TA審稿-二輪評分-Ch4-10重構版-2026-07-04.md`（二輪）。格式照抄即可。

## 一輪報告

```
# TA 審稿回饋｜{對象}（{日期}）
> 審稿對象 / 方法 / 驗證聲明（三行）
## 0. 一頁摘要
   分數表（persona｜分數｜一句話）＋核心結論＋最高優先修改（多來源收斂條目，標來源）
## 1. 各 persona 審稿全文（照錄）
## 2. 修改建議收斂清單（表格：# | 建議 | 位置 | 層級[內容/行銷/政策] | 來源；按 P0/P1/P2）
## 3.（如有研究員）研究附錄含全部 URL
## 4. 驗證備註（查證方法與結果、佔位符處理、分數免責）
```

## 二輪報告

```
# TA 審稿｜二輪評分（{對象}）
## 0. 分數對照表（persona｜一輪｜二輪｜Δ｜一句話）＋疑慮解決率＋結構性發現
## 1–3. 各 persona 全文（含疑慮逐條覆核三態）
## 4. 「最後一哩」清單（A 只有委託人能拍板的／B 行銷層的／C 本輪已順手處理的）
## 5. 驗證備註
```

## 多版本盲選 iteration report

```
# persona-review｜iteration report（{對象}）
## 0. 選版結論：argmax 勝者＋pairwise 交叉檢查結果（一致／不一致處）；plateau 判定與停止原因
## 1. 分數軌跡表（per persona × per unit × per 輪；score_ledger.py 產出貼入）
## 2. drop-off 熱點彙整
## 3. 每輪 structured directives（{artifact_id, 問題, 修法方向}）
## 4. 驗證備註
```
