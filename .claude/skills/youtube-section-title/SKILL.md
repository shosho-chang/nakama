# youtube-section-title — 小標題遮罩

**版本：v1.0（2026-11-16）**

YouTube 照稿影片的 DP 由一類一類的小 skill 組成（已有 `youtube-concept-title`、`youtube-book-cover`、
`youtube-person`、`youtube-reframe`、`youtube-chapter-card`）。小標題由稿上的 `###` 自動產生
（規格 §3.4），Director 不判斷；本 skill 只負責把**已經核准**的小標題列做成素材。

修修（規格 §3.4）：「我講話是不會停下來的，所以那一個小標題，我記得之前用的是讓畫面有一個半透明的遮罩，
然後加上字」——所以疊在錄影上、**不插入時間**，跟章節卡把影片切開不一樣。

## 設計（修修逐輪定版，不要自己改）

| 元素 | 定版 | 修修原話／來源 |
|---|---|---|
| 底 | 全畫面深色半透明遮罩 `rgba(40,37,37,0.62)` | 「我想採用深色的遮罩」；「想再更輕量化一點」（跟章節卡碎片框飛進飛出拉開距離） |
| 碎片 | 只在左上、右下兩角。右下＝手冊 `brand-identity.pdf` 第 24 頁「影片開頭」向量原稿右下角那 3 塊（章節卡 POLYS 第 1、4、5 塊，原樣不重畫）；左上＝**同一組沿畫面對角線翻面**，兩角方塊寬度、形狀一致 | 三款輕量版選了「兩角碎片」；「左上角的 pattern 跟右下角的 pattern，它的方塊寬度以及形狀是不一樣的，這樣會變得很奇怪」→ 選翻面這版 |
| 露出多少 | 兩團停住時整團往各自的角外推 160px（橫）／109px（縱），形狀、編排不變 | 「把 pattern 再往外縮一點……形狀跟編排都不要變」；80／120／160／200 四版裡「160 還不錯」 |
| 標題 | 白色思源黑體 Black，一行，水平置中、中心在 y=440；**一個字一個字往上浮**（每字 0.035s，從下 18px） | 沿用探索稿，修修看過截圖選定 |
| 動作 | 遮罩 0.18s 淡入、碎片從角外 0.28s 探進來；2.2 秒起字先淡掉、碎片縮回角外、遮罩最後淡出 | — |
| 長度 | 2.5 秒；安靜、不配音效 | — |

被否決過、不要再提的方向：只壓標題那一條的深色斜邊帶、標題下畫橘線；兩角碎片裁切／縮小／四角都放；
左上用 p24 自己的左上碎片（「左上角擠成一團了」）；左上碎片扇形排開；左上轉 180°（「很奇怪」）；
左上轉 ±20°（放射結構跑掉）。

元件原始檔：`video/compositions/section_title/compositions/section_title.html`（多邊形座標已內嵌）。
改設計＝改這一份，並在 PR 附渲染截圖給修修看過。

## 標題

「畫面上的字」（`onscreen_text`）＝稿上 `###` 的文字，一行。字級最大 96px，字多時自動縮小，讓整行
放在兩角碎片之間（寬 1400px，約 14 個全形字）；縮到 72px 還放不下（約 19 個全形字以上）就擋下來，
請修修縮短 `###`。標題裡的空格會保留。

## 時間

- 從這一列的第一句字幕（`start_cue`）開始，**固定 2.5 秒**，不插入時間、不推後面的錄影。
- 素材帶 alpha，整支疊在錄影上。

## 怎麼跑

```bash
python -m agents.brook.youtube_video.visuals.section_title "G:/Footages/<episode>"
```

- 只渲 `category == section_title` 且 `status == approved` 的列；`--row <id>`、`--force` 同其他元件。
- 一張約 15–20 秒。標題與元件沒變就沿用。

## 交件（所有分類共用的格式，`agents/brook/youtube_video/visuals/delivery.py`）

- `<episode>/visuals/<row_id>.mov`：1920×1080、29.97 fps、ProRes 4444 帶 alpha，2.5 秒（75 格）。
- `<episode>/visuals/<row_id>.json`：收據；`start_sec`＝放在原始錄影的哪一秒、`duration_sec: 2.5`。

## 驗收

1. 指令最後一行是 `N/N 張完成`；有 ✗ 的列回報給修修（通常是標題空的或太長）。
2. 抽一張疊在錄影上看：兩角碎片形狀一致、標題沒碰到碎片、退場後畫面回到錄影。
3. `ffprobe` 確認 `prores 4444`、`yuva444p`、`30000/1001`、75 格。

## 還沒定

- 標題位置（y=440）在修修的錄影上會壓到下巴附近；修修還沒要求改，要改再說。
- 稿上 `###` 自動產生小標題列的程式（初剪／Director 那邊）還沒做；鋪時間軸的程式照上面的時間擺。
