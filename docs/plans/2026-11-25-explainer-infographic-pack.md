# 解釋動畫改成「品牌 infographic 包」（2026-11-25）

- 錨定：CONTENT-PIPELINE 第 5 層「製作」；YouTube 照稿影片畫面分類第 5 類「解釋動畫」，DP 子 skill `youtube-explainer`。
- 起因：修修看了第 5 類的 5 個原型（比例、算式、對比、面板、階梯），指出「這幾個不是模板吧？是因為《財富階梯》這一集
  做出來的動畫」；再拿 Envato「Minimal Infographics for Premiere Pro」對照，問「你要做的是不是就是 Infographic 的 Pack？」
  → 修修裁決「照圖表種類重做」。
- 參考：那個素材包只拿來當**「要涵蓋哪些圖表」的清單**，設計不抄（它是藍色＋Montserrat），全部照品牌積木
  （`video/compositions/explainer/assets/kit/`：冷灰、黑、白、橘、Noto Sans TC Black、手冊碎片）。

## 原則

1. **照圖表種類分，不照題材分**：每一種只認「這個數字長什麼形狀」，換一集、換主題都能用。
2. **沒有預設內容**：內容全部從 spec 來；模板檔裡的預設值只是看版面用的「範例」字樣，不放任何一集的內容。
3. **跟字幕對時間**：每個元素在講到它的那一句出現（`at`＝那句字幕開頭，從這張的 0 秒算）；正在講的那一個橘色，講過的回黑。
   這是素材包沒有、我們要保留的。
4. **驗收＝兩集都套得上**：每一種至少用《財富階梯》與《不平等優勢》（或其他非《財富階梯》的稿）各套一次，
   再加版面壓力測試（最少項、最多項、最長標籤、側欄版），都不出安全框、不重疊。

## 清單

| 圖表 | 數字的形狀 | 素材包對應 | 狀態 |
|---|---|---|---|
| 橫條 `bars` | 幾個數量並排比大小（百分比或同單位數量），≤6 條 | Bars、Single Bar | 定版（修修 2026-11-25） |
| 直條 `columns` | 同上但類別有順序（年份、階段、前後兩組），≤8 根 | Columns、Single Column、Triangles | 定版（修修 2026-11-25） |
| 圓環 `donut` | 一個整體裡的一部分（一個百分比），中間大數字 | Circle Left/Right/Lines | 定版（修修 2026-11-25） |
| 點陣 `dots` | 「百裡挑一」「每 N 個有 1 個」：整體排成格子，只亮幾格 | —（素材包沒有） | 定版（修修 2026-11-25） |
| 圓餅 `pie` | 一個整體分成 2–4 塊 | Pie | 定版（修修 2026-11-25） |
| 大數字 `stat` | 一個驚人的數字＋一句說明 | Timeline 右上的 58.1% | 定版（修修 2026-11-25） |
| 折線 `line` | 隨時間變化（存錢、複利、成長），1–2 條 | Lines | 定版（修修 2026-11-25） |
| 刻度 `axis` | 一條軸上標幾個點（年份、等級、門檻、一把尺），可加指標 | Timeline | 定版（修修 2026-11-25） |
| 算式 `equation` | 拿實際數字算一次 | — | 定版（修修 2026-11-25：「把 infographic 做完」；直式排法） |
| 對比 `contrast` | 兩組東西對照 | — | 定版（修修 2026-11-25：「把 infographic 做完」） |

**選圖先問「要觀眾看出什麼」，不是「有幾個數字」**（修修 2026-11-25：「400 多人選 4 個人……要強調比例很小，
應該是用圓餅圖才對」——同樣兩個數字，橫條講的是「誰比較大」，這句要講的是「4 個只佔 400 個的一小塊」）：

| 要觀眾看出 | 用 |
|---|---|
| 幾樣東西誰大誰小 | 橫條／直條 |
| 一小部分佔整體多少（「只有 8%」「一半一半」） | 圓環（2–4 塊才用圓餅） |
| 很小的整數比（「400 個選 4 個」「每 10 個有 1 個」） | 點陣（不用讀數字也懂）；比例超過約 20% 或不是整數比 → 圓環 |
| 一個數字本身很驚人 | 大數字 |
| 怎麼變化 | 折線 |

**移出這一類**：面板（RPG 角色面板）、階梯（像素修修爬樓梯）是比喻、不是圖表——歸到漫畫／主角演出，有需要時照分鏡表做。
**不做**：地圖（頻道內容少用，要時再談）。

## 接上 DP（2026-11-25）

- DP 寫圖表規格 `<episode>/visual_sources/<row_id>.json`（時間寫字幕句號＋offset），`visuals/explainer.py` 把句號換成秒數、
  檢查必填與數量、用無頭 Chrome 量版面（`explainer-kit.js` 的 `check()`：字超出安全框、兩段字重疊就擋），再渲成交件。
- `dp.py` 的 `RENDERERS` 加 `explainer`；側欄版收據 `layout: overlay` → 鋪時間軸時臉讓到左 1/3（`reframe.LAYOUT_MOVES`）。
- 欄位與規格檔格式：skill `youtube-explainer/charts.md`。

## 圖表：橫條 `bars`

spec 欄位：

| 欄位 | 必填 | 說明 |
|---|---|---|
| `layout` | ✓ | `full`（滿版）或 `overlay`（右側欄，人讓到左 1/3） |
| `title` | ✓ | 標題（關鍵詞，≤12 字） |
| `source` | | 出處，印在右上 |
| `show_sec` | ✓ | 這張停留秒數 |
| `unit` | | 單位，預設 `%`；百分比刻度固定 0–100，其他單位以最大的那一條為滿 |
| `max` | | 指定滿刻度（例：要讓 4 人對 400 人，max＝400 是預設，不用填） |
| `digits`、`prefix` | | 小數位、數字前的單位（`NT$`） |
| `items[]` | ✓ | `{label, value, at, digits?, suffix?, prefix?}`；`suffix` 蓋掉 `unit`（例：「400 多人」） |
| `rest_at` | | 這一刻全部回黑 |
| `mark` | | `{item, at, text}`：把第幾條再點亮，軌道右端斜貼黑牌（一個畫面只一張） |

版面規則（程式自動算）：條數 ≤4 數字 96px、標籤 60px；5–6 條數字 84px、標籤 48px；側欄數字 88／72px、標籤 40px。
標籤欄寬＝最長標籤（上限 560px）。

## 圖表：圓環 `donut`

1–3 個環並排（側欄最多 2 個上下排）。比例照實畫，1% 的弧就是很細，靠中間的大字撐。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `layout`、`title`、`source`、`show_sec` | | 同橫條 |
| `items[]` | ✓ | `{label, value, at, total?, center?, digits?, label_at?}`：給 `total` 就算 `value/total`（例：4／400＝1%）；只給 `value` 當百分比；`center` 換掉中間的字（例：「1 : 1」） |
| `rest_at` | | 這一刻全部回黑 |

尺寸：滿版 1 個直徑 500、2 個 440、3 個 380；側欄 1 個 440、2 個 250。環粗＝直徑 16%，從 12 點鐘順時針畫。

## 圖表：點陣 `dots`

整片格子先長出來，講到那個數字時被挑中的格子變橘、彈一下；旁邊（側欄是下面）一行一行出字。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `layout`、`title`、`source`、`show_sec` | | 同橫條 |
| `total` | | 格數，預設 100，最多 200（≤100 排 10 欄、更多排 20 欄） |
| `lit` | ✓ | 亮幾格 |
| `pick` | | 亮哪幾格（0 起算）；沒給就從第一格開始 |
| `dots_at`、`lit_at` | ✓ | 整片出現、亮格的秒數 |
| `lines[]` | | `{text, at, big?}`；`big`＝那個關鍵數字，橘色大字 |
| `note`、`note_at` | | 換算說明。**真實數量不是格數時一定要寫**（例：400 人畫成 100 格 →「每 1 格＝4 人」），不然觀眾以為真的只有 100 個 |

## 圖表：大數字 `stat`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `label`、`label_at` | | 數字上面那行：這是什麼的數字（「第 4 階家庭的年齡中位數」） |
| `value`、`at` | ✓ | 數字與它跳出來的秒數；`digits` 小數位 |
| `before`／`prefix`／`suffix` | | 數字前的小字（「超過」「約」）／前置單位（`NT$`）／單位（「 歲」「 人」） |
| `desc`、`desc_at` | | 數字下面補一句 |

數字滿版 300px、側欄 200px，放不下自動縮到剛好；上下兩行說明太長也一樣縮（不換行）。

## 圖表：直條 `columns`

欄位同橫條（`items[]`、`unit`、`max`、`digits`、`prefix`、`rest_at`），沒有 `mark`。≤8 根；數字或標籤比柱子那一欄寬就自動縮字。

## 圖表：圓餅 `pie`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `parts[]` | ✓ | `{label, value, at, digits?, pct_text?}`；2–4 塊，百分比＝value／total 自動算 |
| `total`、`total_at` | | 整體的數量與整個圓出現的秒數。給了 `total`，沒講到的部分自動變成一塊（`rest_label`，預設「其他」，跟最後講到的那一塊一起切出來；`rest_part_at` 可指定） |
| `rest_at` | | 這一刻全部回原色 |

顏色：黑、深灰、淺灰、白（依序），正在講的那一塊橘色；旁邊圖例＝色塊＋名稱＋百分比。

## 圖表：折線 `line`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `series[]` | ✓ | 1–2 條：`{points:[[x,y]…], at, until, name?, end_text?, end_label?}`；線從 `at` 畫到 `until` |
| `x` | ✓ | `{ticks:[…], unit?, labels?, min?, max?}`：底線上的刻度 |
| `y` | | `{unit?, prefix?, digits?, max?}`：終點數值的格式 |
| `marks[]` | | 中途要標數值的點 `{x, y, text?, at}` |

不畫格線、不畫 y 軸；要觀眾看的數字直接標在點上。**要實算的線（複利）由程式照稿上的假設算好再填 points**；稿上沒有的假設不能自己編。

## 圖表：刻度 `axis`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `points[]` | ✓ | `{label, sub?, at, pos?}`：名稱在軸上方、`sub`（數字、年份）在下方；都有 `pos` 就照數值等比例排，否則等距；≤8 個 |
| `axis_at` | | 軸畫出來的秒數 |
| `pointer` | | `{index 或 pos, at, text}`：橘色三角形＋一行字，指出「重點在這」 |
| `rest_at` | | 這一刻全部回黑 |

滿版是橫軸；側欄是直軸（上到下），名稱與數字在右邊。
