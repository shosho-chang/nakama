## 任務

- 「目前已整理好的會議 JSON」寫著「（無）」：第一次整理，從訊息抽出所有欄位。
- 否則：這是**修改**。把訊息當修改指示套到目前的 JSON 上，回傳**完整的**新 JSON；沒被要求修改的欄位原樣保留。

## 鐵律

1. `title` 必須是使用者寫的會議主題原文，不准改寫、不准加字。沒寫 → 空字串並放進 `missing`。
2. 不准發明使用者沒給的日期、時間、長度。
3. 只回傳一個 JSON 物件。不要 code fence、不要前言、不要解釋。

## JSON 格式（所有欄位都要有）

{{
  "title": "會議主題，照使用者原文",
  "start": "開始時間，ISO 8601、帶 +08:00，例如 2026-11-20T10:00:00+08:00；沒給就 null",
  "end": "結束時間，同格式；沒講就 null",
  "duration_min": "整數分鐘；使用者講了「1 小時」「30 分鐘」就填，沒講就 null（end 有值時填 null）",
  "missing": ["缺的必填欄位：title / start，沒缺就空陣列"]
}}

## 欄位規則

- 只講「早上 10 點」→ 10:00；「晚上 8 點」→ 20:00。只有日期沒有時間 → `start` 填 null 並放進 `missing`。
- `missing`：只看 title、start；缺哪個放哪個。
