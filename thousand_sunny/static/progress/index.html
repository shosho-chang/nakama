04 structural observations

三條優先序 — 不解，後面都會撞同樣的牆

  1. [01]

    IG 半自動發布管線

    Line 1/2/3 IG carousel 都 render 完，卡在 Stage 6 last mile。先解 PNG batch 出檔 + Buffer · Later 排程匯入，不必硬啃 IG Graph API。最低工自動化、最高 摩擦消除。

  2. [02]

    Annotation → KB 整合 owner

    Line 2 讀書心得 critical path。Reader UI 已支援 highlight + annotation， 但寫到哪、誰讀、何時用完全未設計。具體實作待修修手跑 Line 2 一次後再凍結。

  3. [03]

    SEO 中控台 → Zoro 反向 feed

    Discovery → Production → Insight 迴路斷裂。SEO 中控台抓出 striking-distance 關鍵字沒回灌 Zoro 變下次主題建議。一條 SQL view + Zoro report 加 section， 一週可閉環。
