06 migration · phased

遷移步驟

不一次全做。每個 Phase 小範圍、可獨立驗證、舊路徑保留 301 redirect 一段時間以免 bookmark 失效。

phase 1 Shosho marketing landing（沒有破壞性變更）
建 / 的 Shosho marketing landing（取代目前 302 → /brook/bridge）。修修 bookmark 改用 /brook/context（即將是新名稱）或 /bridge（Bridge ops）。同時加 301 redirect：/brook/bridge → /brook/context，這樣 muscle memory 不會立刻斷。
phase 2 Brook prefix 統一（4 個 rename）
/projects/{slug} → /brook/projects/{slug}、/brook/bridge → /brook/context、/promotion-review/* → /brook/promotion/*、/writing-assist/{id} → /brook/writing/{id}。每個改名加 301 redirect 從舊路徑，保留 30-60 天再刪。
phase 3 Robin prefix 統一（6 個 rename，僅 local 影響）
/（Robin enabled）+ /read + /processing + /done + /review-* + /books/* → /robin/*。本機環境，沒有 partner / SEO 影響，可以無痛換。
phase 4 技術債清理（無使用者影響）
抽 --nk-* Bridge tokens 從 20+ template 的 inline <style> 到 thousand_sunny/static/bridge/tokens.css。刪除 deprecated /bridge/health。刪舊 301 redirects 在 Phase 2/3 通過後。
