# 修修人物介紹文風格側寫（Centaur KB Style Extractor v2 + v1 規格層）

> 適用：張修修（修修）《不正常人類研究所》podcast 來賓介紹文 / 人物故事。供下游 AI 寫作 agent 套用、模仿其聲音。
>
> 本文件為合併版：**主體（§1–§9）來自 v2 盲抽聲音骨幹**，逐字原文引用 + slug 完整保留；**§10–§14 為從 v1 規格層 graft 進來的五塊操作框架**。任何衝突一律以 v2 為準。

## 1. 文章定位

這類文章是 **podcast 來賓的「人物故事側寫」**，不是訪談逐字稿、不是書摘、也不是個人成長教學文。它的功能有三：

1. **幫讀者快速認識一位來賓**——通常是某領域「很厲害的人」，把他的學經歷、代表作、頭銜濃縮成幾段。
2. **用一個懸念把讀者推去聽 podcast**——文章從不把故事講完，永遠留一個「他到底怎麼辦到的？」的鉤子，明示暗示「答案在節目裡」。
3. **傳遞節目核心世界觀**——節目叫《不正常人類研究所》，所以每篇都在論證「這個人有多『不正常』（=非凡）、為什麼值得研究」。文章定位 ≈ 一封「熱血推薦信」+「電影預告片」。

調性是 **崇拜但不諂媚、熱血、帶感染力**。修修常以「朋友 / 粉絲 / 同業」的身分現身，不是冷靜的第三方記者。它服務的是「讓你想點開那一集」，不是「讓你看完就不用聽了」。

## 2. 聲音指紋

每條附一句逐字原文引用 + slug。

1. **用 ACG / 電玩 / 漫畫框架包裝真實人物**——這是最強指紋，幾乎每篇都有。把人生說成「練等、開地圖、技能樹、偉大的航道」。
   - 「常人看起來很不可思議的挑戰和轉變，在他看來只是另一個開地圖和打怪的過程。只是地圖越開越大，怪的等級越來越厲害而已。」（ep48-adam）
   - 「阿嘉是我認識的人裡面最像魯夫的人。」（ep31-aga）

2. **「不正常 / 怪人 / 奇葩」是最高讚美**——節目宇宙裡，「不正常」=值得研究的非凡，帶寵溺。
   - 「他是我的朋友裡完全符合『行為舉止怪異』＋『人生選擇不正常』這兩個標準的怪人，當然要把她請來節目聊聊。」（ep07-wanting）
   - 「（果然是個不正常人類⋯⋯）」（middle-age-new-chapter-marctien-podcast-ep75）

3. **修修以第一人稱現身、頻繁夾敘自己的關係與反應**——「我的好朋友」「我的偶像」，故事不是客觀轉述而是「我帶你認識我這個朋友」。
   - 「今天的來賓是我的偶像：成大資工系的教授蘇文鈺老師。說真的能被我當成偶像的人真的不多，不只要很厲害而且要很不正常。」（ep35-alvin-su）

4. **段末懸念反問句作鉤子**——一段資訊鋪陳完，用一句獨立成段的反問把讀者懸住，明示答案在節目。
   - 「她到底是怎麼辦到的？」（ep36-yichan-lin）
   - 「這跟她人畜無害的形象也差太多了吧？」（ep58-jill-chang）

5. **台灣口語助詞 + 俚俗成語混搭書面語**——「啦、齁、欸、喔對了」與「盆滿缽滿、托缽、首當其衝」同框，口白感重。
   - 「說他形象好長得帥嘛，是沒錯啦」（ep006-ray-du）
   - 「喔對了，連咖啡都是他自己烘的。」（ep35-alvin-su）

6. **誇張對比 / 反差身份開場**——先抛出一個張力極大的反差（學霸卻進偏鄉、千金變打工、內向卻上百場演講），製造認知失調。
   - 「外表甜美，個性極度安靜、內向，連被早餐店老闆搭話都會驚慌失措的她，卻有上百場國內外演講的經驗」（ep58-jill-chang）

7. **金句引言獨立置中 + 破折號署名**——每篇正中間放一句來賓的人生格言，獨立成 `## 段落`，下一行 `－姓名`。
   - 「『你註定要做一件只有你能做的事情。』／－龔建嘉」（ep31-aga）

8. **熱血召喚式收尾**——結尾常直接呼告讀者「一起來聽 / 一起來追 / 別忘了打招呼」，把讀者拉進故事裡。
   - 「魯夫還在成為海賊王的路上，我相信阿嘉的熱血故事也是連載上演中，值得我們一起來持續追下去。」（ep31-aga）

9. **括號吐槽 / 補充小聲話**——用全形括號夾一句私語式的吐槽或自嘲，製造親近感與幽默。
   - 「她超強（不要臉）的三寸不爛之舌」（ep07-wanting）
   - 「（除了學一天就發覺自己完全不是那塊料的芭蕾舞）」（ep07-wanting）

10. **數字堆疊作「神蹟」證據**——用具體營收 / 訂閱數 / 國家數 / 集數密集轟炸，把「厲害」量化成不可辯駁的事實。
    - 「將鮮乳坊經營成了一間年營收超過 4 億的公司」（ep31-aga）
    - 「管理從東到日本、西到阿富汗、北到蒙古、南到澳洲的二十五個國家。到職兩年內幫助募款翻倍」（ep58-jill-chang）

## 3. 敘事結構骨架

幾乎是固定模板，**章回式**（每章一個 `##` 小標，標題本身就有戲）：

```
[frontmatter：title 開頭 🧠 + 節目名 + EPxx｜姓名：一句話定性副標]
│
├─ ## Episode XX
│   └─ > blockquote 導語（懸念總綱，bold，以反問收尾「他到底怎麼辦到的？」）
│
├─ 開場 2–4 段：第三人稱介紹來賓 + 修修跳出說「我為什麼想訪他」
│   └─ 拋出「但我真正好奇的是…」式的核心懸念
│
├─ ## 章回 1（出身 / 起點，常是低谷或反差）
├─ ## 章回 2（轉折 / 試煉）
│
├─ ## 『一句人生金句』   ← 置中獨立，下一行「－姓名」
│
├─ ## 章回 3、4…（崛起 / 代表作 / 數字神蹟）
│   └─ 穿插 _[圖：圖說]_ 佔位
│
└─ 收尾段：熱血展望 + 召喚讀者去聽 / 去追 + 相關連結清單
```

關鍵結構特徵：
- **來賓用第三人稱敘事為主幹**（「她」「他」「阿嘉」），修修以第一人稱**間歇跳出**當鏡頭（「我發現…」「我一直很好奇…」「我想…」）。兩種視角交織，但比例上第三人稱敘事 >> 修修自陳。
- **金句引言固定置於全文中段**，是結構的「定錨點」，不是結尾。
- 小標**本身帶敘事張力**，不是中性章節名：例如「千金難買少年窮」「捨我其誰？更待何時？」「不練則已，一練發現自己是練跑奇才」。
- **圖說用 `_[圖：…]_` 斜體佔位**，圖說常帶吐槽（「……不知道他們想說什麼是害人害己」ep31-aga）。

## 4. 開場鉤子（分型 + 原文例 + slug）

導語 blockquote 與開場段落的鉤子分幾型，常複合使用：

**A. 反差身份型**——並列兩個看似矛盾的標籤，製造認知失調。
- 「外表甜美，個性極度安靜、內向，連被早餐店老闆搭話都會驚慌失措的她，卻有上百場國內外演講的經驗，還在到職非營利組織 Give2Asia 的兩年內讓募款金額翻倍，被美國同事稱為『台灣來的怪物』。她是怎麼做到的？」（ep58-jill-chang）
- 「頂著這樣亮麗的學經歷，為什麼不循著一條輕鬆有『錢』途的路，而是一頭栽進偏鄉，做一些旁人眼中傻子才做的事情？」（ep35-alvin-su）

**B. 懸念反問型**——堆完成就後，用一句「他到底怎麼辦到的？」把答案藏進節目。
- 「兩年過後，他不但成了十大傑出青年，還將鮮乳坊經營成了一間年營收超過 4 億的公司，他到底怎麼辦到的？」（ep31-aga）
- 「今天的訪談，終於讓我把那些關鍵因素全部拼湊起來了。」（ep006-ray-du）

**C. 數字神蹟型**——先用一串驚人數字砸暈讀者，再丟一個「但…」轉折。
- 「創立之後第一個月的營業額就破百萬，最高峰的時候有三千六百萬的庫存，年營收三億…但創辦人在品牌如日中天…的時候，從公司裸退，把自己的股份全部讓給合夥人了。」（ep07-wanting）

**D. 私人軼事型**——以修修和來賓的私交場景破題，瞬間拉近距離。
- 「和阿嘉是兩年前在墾丁潛水認識的。當時一邊喝著啤酒一邊天南地北地閒聊，那時候就覺得，這個人怎麼那麼像漫畫人物啊。」（ep31-aga）

**E. 哲理/共鳴提問型**（較新、較長文用）——對讀者拋出一個人生大哉問，把來賓塑成解答的化身。
- 「大家是否心中總有一個夢想，卻遲遲不敢實際去追尋？…追夢永遠可以從今天開始。」（middle-age-new-chapter-marctien-podcast-ep75）

**F. 場景特寫型**——直接以一個畫面/對話切入，不先報頭銜。
- 「晨泳的長輩很多都是身懷絕世武功的怪物…『少年耶，我看你漢草這麼好，啊怎麼游那麼慢啊？』」（ep50-sean-wang）

## 5. 語氣與稱謂

- **第三人稱敘事為主**（占比約 70–80%）：以來賓的名 / 暱稱 / 「他/她」推進；修修第一人稱（「我」）穿插約 20–30%，集中在開場「為什麼想訪他」與收尾「我相信 / 我想」。
- **暱稱化稱呼拉近距離**：偏好用親暱簡稱而非全名——「阿嘉」「阿滴」「魁哥」「象總」「婉婷」；正式頭銜（「蘇老師」「怡辰老師」）用於師長型來賓表敬意。
- **台灣口語助詞高頻**：「啦、齁、喔、欸、嘛、啊」貼在句尾製造口白感。例：「太貴了齁！」（ep36-yichan-lin）、「是沒錯啦」（ep006-ray-du）。
- **流行文化 reference 是 DNA**：
  - 《海賊王》——「魯夫」「船長」「偉大的航道/航路」「成為海賊王」（ep31-aga、ep006-ray-du）
  - 電玩——「打怪升等」「技能樹要怎麼點」「開地圖」「裝了 Turbo」「練等」（ep48-adam、ep006-ray-du、ep50-sean-wang）
  - 漫畫/日劇——「像漫畫人物」「只有漫畫才看得到的慘劇」「彷彿日劇般熱血」（ep31-aga、ep07-wanting、ep36-yichan-lin）
  - 電影——「效法電影《永不放棄》，他單挑整個國防部」（ep31-aga）
- **括號私語**：全形括號夾吐槽/自嘲/補充，是固定習慣。「（不要臉）」「（現在老公）」「（果然是個不正常人類⋯⋯）」。
- **emoji 慣例**：**正文幾乎不用 emoji**。emoji 只出現在 frontmatter `title` 開頭的 `🧠`（節目固定識別），是節目品牌標記，不是內文修辭。下游寫作時內文不要灑 emoji。
- **成語/俚語混書面**：「盆滿缽滿」「托缽」「首當其衝」「乏人問津」「捨我其誰」「望梅止渴」與口語並用，文白交錯。

## 6. 段落節奏

- **段落極短**：絕大多數段落 1–3 句，常常**一句一段**，尤其是轉折句、懸念句、金句式總結。視覺上留白多、節奏快，像口說斷句。
  - 例：「沒想到，奇蹟發生了。」（ep36-yichan-lin，獨立一段）
  - 例：「她到底是怎麼辦到的？」（獨立一段作鉤子）
- **全文字數**：約 1,100–3,900 字（meta word_count 中位數 ~2,400），偏短文；越早期/越大咖越長，後期人物故事更精練。
- **引述來賓原句的手法**有三種：
  1. **「全形引號」直接引語**鑲進敘事，多為來賓金句或關鍵對白：「『因為這是軍中的財產，就像一支槍一樣。』」（ep31-aga）。
  2. **置中金句 blockquote/獨立段 + 破折號署名**（見 §7），全文一次。
  3. **轉述 + 引號重點詞**：把來賓的關鍵概念用引號標出再展開，如「『動機』和『環境』是兩個決定性的因素」（ep006-ray-du）。
- **長 blockquote 用於引用第一手文獻**（募資文案、來賓書信），原汁原味貼上，不改寫：ep31-aga 整段貼了 flyingV 募資文案。
- **節奏推進靠「但 / 沒想到 / 結果 / 於是 / 這時候」**這類轉折/承接連接詞起段，製造劇情起伏：「但她的磨難並沒有結束。」「沒想到，奇蹟發生了。」「這時候，改變他人生軌跡的一件大事發生了」。

## 7. 收尾慣例

收尾**幾乎都是「預告片感 + 召喚行動」**，極少留白冷收。分型：

- **展望/連載式（最常見）**：把來賓的人生比作「還在連載的熱血漫畫」「還沒攻頂的下一座山」，邀讀者一起追。
  - 「魯夫還在成為海賊王的路上，我相信阿嘉的熱血故事也是連載上演中，值得我們一起來持續追下去。」（ep31-aga）
  - 「到底 Adam 這種不斷點擊不同領域的技能樹…還會帶給大家甚麼驚喜呢？他的故事真的值得大家一起來關注。」（ep48-adam）
- **直接召喚讀者行動**：呼告讀者去聽節目、去做某事、甚至去現場打招呼。
  - 「歡迎你穿起跑鞋，踏出第一步，一起成為勇敢追夢的人。」（middle-age-new-chapter-marctien-podcast-ep75）
  - 「如果你在台大田徑場或福和橋下看到象總跑步的身影，別忘了和他打聲招呼喔。」（ep50-sean-wang）
- **金句迴響式**：以來賓或節目座右銘作結，餘韻收尾。
  - 「『你不需要很厲害才能開始，你要開始才能變得厲害。』」（middle-age-new-chapter-marctien-podcast-ep75）
- **懸念續集式（上集文章）**：故意停在劇情高潮，明示「下集待續」。
  - 「就在快到目的地時，婉婷一放鬆心情，發生了一件只有漫畫才看得到的慘劇……」（ep07-wanting，標題即標「（上）」）
- **連結清單收尾**：正文結束後附來賓的 FB / 官網 / 著作 / podcast 連結（markdown link list），是固定收尾元件。

留白型（如 ep58-jill-chang 以「她其實沒有超能力，她只是活出了最好版本的自己。」金句靜收）存在但較少，且仍帶情感餘韻、非冷收。

## 8. 絕不這樣寫（NEVER-DO）

從樣本反推，**最高價值**。下游 agent 違反任一條即偏離修修聲音：

1. **絕不把故事講完、絕不破梗**。文章是「鉤子」不是「解答」。關鍵的「他怎麼辦到的 / 後來怎麼了」要留在 podcast 裡。樣本一致以反問或「答案在節目」收束（ep07-wanting 甚至停在車禍前一刻）。**寫成完整傳記 = 致命錯誤**。

2. **絕不用冷靜中立的第三方記者口吻**。修修永遠帶情緒、帶崇拜、帶私交（「我的偶像」「我的好朋友」「果然是個不正常人類」）。**禁止** wikipedia 式無感平述。

3. **絕不用 emoji 裝飾內文**。`🧠` 只屬於 frontmatter 標題的節目標記。內文靠文字節奏與口語助詞營造情緒，**不靠 emoji**。

4. **絕不用 AI slop 的均勻結構與通用過渡**。禁止「首先…其次…最後…」「總而言之」「綜上所述」「在當今社會」這類八股；禁止每段等長的工整段落。修修是**長短句劇烈交錯、常一句一段**。

5. **絕不漏掉「不正常 / 怪 / 熱血」這層節目世界觀**。每篇都在論證來賓有多「非凡值得研究」。**寫成普通名人專訪、抽掉這層 framing = 失去靈魂**。

6. **絕不用空泛形容詞代替具體數字與軼事**。不要寫「他很成功很厲害」，要寫「年營收 4 億」「54 天跑了全美 30 座大聯盟球場」「管理 25 個國家」。**厲害必須被量化或被一個畫面證明**。

7. **絕不錯置或省略置中金句**。每篇正中段必有一句來賓人生格言，獨立成段、`－姓名` 破折號署名。**不要放結尾、不要用普通引號混在內文、不要省略**。

8. **絕不用生硬書面語取代台灣口語質地**。要保留「啦/齁/喔/欸」助詞、全形括號吐槽、俚俗成語（盆滿缽滿、托缽）。**寫成純正式書面語 = 不像修修**。

9. **絕不改寫第一手引用**（募資文案、來賓書信、來賓原話對白）。要原汁原味用 blockquote 或「全形引號」貼上，保留其質地（如 ep50 阿嬤的台語「少年耶…啊怎麼游那麼慢啊？」）。

10. **絕不用紫漸層式通用 CTA 收尾**（「立即訂閱」「快來看看吧」式空泛行銷語）。修修的召喚是**具體又熱血**的：「穿起跑鞋踏出第一步」「看到象總別忘了打招呼」「一起追下去」。

## 9. few-shot 範本

挑 3 段最具代表性的摘錄，標出處與「為什麼代表」。

### 範本 A — ACG 框架 + 第一人稱崇拜開場（ep31-aga）

> 阿嘉是我認識的人裡面最像魯夫的人。
>
> 善良，有同情心，極富正義感，無可救藥的理想主義者，還有那股一不小心就會自燃的熱血。

**為什麼代表**：濃縮了三大指紋——(1) 以《海賊王》魯夫類比真人，(2) 修修第一人稱現身（「我認識的人」），(3) 一句一段的短促節奏 + 名詞排比堆出熱血感。這是修修人物介紹的「定番開場」。

### 範本 B — 段末懸念反問鉤子（ep58-jill-chang）

> 她現在任職於 Give2Asia 亞太經理，管理從東到日本、西到阿富汗、北到蒙古、南到澳洲的二十五個國家。到職兩年內幫助募款翻倍，美國同事稱她為「台灣來的募款怪物」。
>
> 這跟她人畜無害的形象也差太多了吧？

**為什麼代表**：示範「數字神蹟（25 國 / 募款翻倍）+ 反差身份（人畜無害 vs 募款怪物）+ 獨立成段的口語反問鉤子（『差太多了吧？』）」三件套——把答案懸在節目裡的標準手法。

### 範本 C — 熱血展望 + 召喚行動收尾（middle-age-new-chapter-marctien-podcast-ep75）

> 如同《跑步不要聽》的座右銘所說：
>
> 「跑步不難，難的是穿上跑鞋離開家門的那一刻。**你不需要很厲害才能開始，你要開始才能變得厲害。**」
>
> 僅用這集節目，將田鴻魁「魁哥」的故事和信念送給大家。
>
> 歡迎你穿起跑鞋，踏出第一步，一起成為勇敢追夢的人。

**為什麼代表**：示範修修的標準收尾——先以一句金句迴響定調，再用**具體而非空泛的召喚**（「穿起跑鞋，踏出第一步」）把讀者拉進故事、推向行動，餘溫熱血，不冷收、不用通用 CTA。

## 10. 書評 vs 人物文 邊界框架（防混淆）

下游 agent 最常見的偏離，是把人物文寫成書評（standalone 知識產品）。兩者沿三軸對比，寫人物文時務必站對位置：

| 對比軸 | 書評 | 人物文 |
|--------|------|--------|
| **功能定位** | 獨立知識產品——目標是「讓讀者理解一本書的核心概念並被說服去讀」。修修站「知識翻譯者」位置，把論點拆開、用例子重組，讀完就有 takeaway。 | podcast 的「前菜」——目標是「讓讀者被這個人吸引，點進 podcast 聽完整故事」。修修站「嚮導」位置，文章是「擺一條通往 podcast 的鉤子」，讀完會想去聽。 |
| **段落節奏** | 偏長段落（4–8 句一段）+ bullet list 整理論點；引用書中原句、段落化整合。 | 偏短段落（2–4 句一段）+ 單句斷點，像「一格一格的漫畫分鏡」；引用來賓一句話（短而有力，不整段搬，超過 3 句即過長）。 |
| **修修露出度** | 修修相對隱身，是無聲的「知識翻譯者」。 | 修修主動跳進來當角色（「我認識的人裡面最像魯夫的人」「迴向給我父親」）——因為「我認識他 / 被他感動」本身就是對讀者的情感背書。 |

衍生鐵則（皆為人物文側）：
- 人物文**不需要把故事說完**，要留懸念；書評結尾做總結，人物文結尾留懸念。
- 人物文**不需要完整論證**，靠情感與反差帶動。
- 人物文**不用 bullet list 整理人物成就**（書評慣用手法，會破壞敘事感）；改用具體事件 / 反差句 / 數字。

## 11. 來賓三分型矩陣

依來賓類型切換稱呼、語氣、比喻素材與修修露出度。三型常有交集（如「有私交的學界權威」），以主軸歸類後再微調：

| 來賓類型 | 稱呼方式 | 語氣 | 比喻素材 | 修修露出度 |
|---------|---------|------|---------|-----------|
| **A 類：學界 / 專業權威**（醫師、學者、作家） | 全名 + 職稱／先生／醫師（蘇老師、朱為民醫師、張瀞仁 Jill） | **敬意 + 距離**，保留修修自己的思考 | 書籍、學術概念、哲學家引言 | 低到中（除非有私人連結則拉高） |
| **B 類：創業家 / 實踐者**（品牌主理人、講師） | 綽號 / 先生哥姐（阿嘉、福哥、暢哥、象總） | **熱血 + 戲謔**，敢用「變態」「魯蛇」等強字 | 動漫、電影、球類比喻 | 中到高（朋友關係可直接破牆） |
| **C 類：生活家 / 旅人 / 跨界青年** | 英文名 / 暱稱（Jordan、Adam、Winnie） | **讚嘆 + 看好未來**，語氣年輕 | 世代命題（FIRE、數位游牧、Z 世代、增量思維） | 中（以「嚮導介紹後輩」姿態） |

關鍵尺度：對權威是**敬意 + 距離**；「變態 / 魯蛇」這類強字**只用在朋友 / 同輩（B 類）**，不可錯用到 A 類權威身上。

## 12. 字數三檔分級

字數依來賓「人生弧線長度」與熟識度分三檔，不是一刀切：

- **新銳 / 短生平來賓**：**1000–1500 字**（如 ep43 SaLLy 988 字）。
- **主流區間**：**2000–3000 字**（多數人物文落在此區）。
- **好友 / 長人生弧線**：**3000–4000 字**（如 ep27 琦恩、ep21 福哥、ep09 Jordan）。

對齊 v2 §6 觀察：越早期 / 越大咖越長，後期人物故事更精練。

## 13. 稱謂漸近親近化動態

稱謂不是靜態固定，而是**在文中逐漸親近化**，製造「讀者與修修一起越來越熟」的共同體驗：

- **開場**：用正式全名 / 全名 + 職稱（建立「這人值得聽」的份量）。
- **中段**：轉成暱稱 / 綽號或「他 / 她」。
- **規律**：「隨著我們越認識他，我們也越自然地叫他福哥」——越往後、越熟，越自然地叫暱稱。

此動態與 §5「暱稱化稱呼拉近距離」「正式頭銜用於師長型來賓」並行：起手敬稱建立距離，行文中再隨敘事推進收攏距離。

## 14. 情感迴向式結尾型

除 §7 已列的展望式 / 召喚行動式 / 金句迴響式 / 懸念續集式 / 留白定格式外，補一個**重量級但罕用**的收尾型：

- **情感迴向式**——以全文最高情感強度收尾，把修修自身的生命情感灌進結尾。罕用，僅在修修與來賓有極深私人連結時動用。
  - 「最後，我願將此文以及此集節目所做功德，迴向給我的父親張貴富先生，願您這條路上能有諸佛菩薩的護持，超生善道，我們來日一定會再見面的。」（ep67 朱為民，迴向父親）

使用時機：權威來賓 + 私人情感結合的最高強度案例（如 ep67 朱為民談死亡，修修迴向父親）。一般人物文不動用此型，以免情感過載失真。
