# Feedback — 禁用「不是 X，而是 Y」對比句型（AI slop 第一名）

**Type:** feedback
**Created:** 2026-08-26
**Confidence:** high（修修多次口頭指正，此次明言「我已經說過很多次不要出現了」）

## 事實

修修反覆指正過同一件事：**「不是……而是……」這種對比句型是 AI slop**，不要出現在任何
產出裡。2026-08-26 他在 review 十年航海圖時再次抓到——文件裡有 40+ 處。

代表性違規（我自己寫的）：

- 「最高的北極星**不是**任何數字，**是**一個問題」
- 「沒報名**不是**落隊，**是**這一季選擇不玩」
- 「量的**不是**幾則，**是**引發多少人回應」
- 「等級**不是**頭銜，**是**你的船航行到哪座島」

## Why

這個句型是 LLM 產物的指紋級特徵：它用**否定一個稻草人**來製造深刻感，實際資訊量等於
只講後半句。連續出現時整篇文章會有濃厚的「AI 寫的」腔調——對一個要對外營運十年的品牌
文件是致命傷。修修對文字的敏感度很高，這是他反覆糾正的**同一條**，不是新要求。

**為什麼一再復發**：我從沒把它寫進記憶。口頭指正在對話結束後就蒸發，下一份文件照犯。

## How to apply

**寫任何文字（方案、文案、commit message、對修修的回覆）前後都要自查這個句型。**

改法是**直接講結論、砍掉否定的前半句**：

| 違規 | 改寫 |
|---|---|
| 最高的北極星不是任何數字，是一個問題 | 最高的北極星是一個問題：會員有沒有真的養成好習慣？ |
| 沒報名不是落隊，是這一季選擇不玩 | 沒報名的人這一季選擇不玩，完全正當 |
| 量的不是幾則，是引發多少人回應 | 量的是一篇文引發多少**人**回應 |
| 等級不是頭銜，是你航行到哪座島 | 等級就是你的船航行到了哪座島 |

**單純否定不算違規**（「62 天不是隨便訂的」「這不是金融系統」）——被禁的是
**「否定 A ＋ 緊接肯定 B」的兩段式對比**。

同族要一起戒的 slop 句型：「與其說……不如說……」、「這不僅僅是……更是……」、
「重點不在於……而在於……」。
