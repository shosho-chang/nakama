長片線從**修修選完三支精華段**那一刻起，**一路做到「B-roll 與所有視覺事件都鋪上
Resolve timeline」為止才回報**。中間任何階段都不要停下來報告進度。

**Definition of Done ＝ 他打開 Resolve，看到一條視覺全部上好的 timeline。**
不是 render、不是輸出、不是 preview 檔——就是 timeline 上東西齊了。

**Why**：2026-09-07 蘇予昕長片線，我在中間停了六、七次回報進度與失敗診斷。修修：
「**我要看到的就是把 B-roll 全部上上去的 Timeline，我真的講過很多次了，你牢牢地記住好嗎？**」

我每次都覺得「這次的發現很重要，值得回報」——但對他來說，沒有到達 DoD 的中途報告
**全部都是雜訊**。技術發現可以在抵達 DoD 之後一次講完，不需要邊做邊播報。

**How to apply**：
- 選段 gate 通過後，接著跑：物化 → 緊湊化 → 導播 → 名牌 → Director → DP → 視覺檢查
  → 視覺鋪軌。**全部自動化，中途不回報。**
- 遇到失敗：自己診斷、自己重試、讓上下游 agent 互相協商。見
  [[feedback_fix_failures_dont_report_them]]。
- 真的卡死到自己解不開，才回報——而且要帶「我試了什麼、為什麼還是不行」。
- 唯一的例外仍是：不可逆／破壞性操作，以及會動到他已定版品牌視覺的設計決定。
