**規則**：subagent 回報的量測結果、根因歸因、以及「我自己驗過了」的自我宣告，
**在拿它去改程式或做決策之前，自己再量一次**。它指出的**現象**通常是真的，
但**歸因**經常是錯的。

**Why**：2026-07-28 逐字稿線兩次踩到。

1. 盲審 agent 說「收工閒聊那段修修的 lav 電平掉到訪談段的 1/4（麥克風拿下來
   了）」，聽起來是一個很好用的自動偵測訊號。我去量 envelope——全片 p95 都在
   −28～−33 dB，**根本沒有掉**。它指出的時間點（3695s）是對的，但那是致謝
   收尾，不是麥克風問題。差點照著一個不存在的訊號做自動偵測。

2. 三個潤飾 agent 都自報「我寫了腳本驗證，去標點後逐字相同」。我還是用自己的
   把關又跑一次。這次剛好都過，但**自我回報不能當數**——同一批 agent 裡就有
   一個承認初版多打了字、自己抓到才修掉。

**How to apply**：
- agent 說「我量到 X」→ 自己量 X，再決定要不要用
- agent 說「我驗證通過」→ 用自己的驗證再跑一次，不採信自我宣告
- agent 說「根因是 Y」→ 現象採信、歸因存疑；改東西前先確認 Y 真的存在
- 但**不要因此不派 agent**：同一輪 review 裡它們抓到的真實缺陷（標點插進詞
  中間、因果被接錯、我的可疑 cue 偵測 0 命中）我自己完全沒看出來
