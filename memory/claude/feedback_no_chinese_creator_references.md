**修修 不要在 thumbnail / title brainstorm 工作中引入中文世界的創作者參考**（如蒼藍鴿、營養師品瑄、Dr.7、阿滴、台大醫師類 KOL）。2026-05-27 thumbnail playbook v1 完工後，Gemini panel audit (`docs/research/2026-05-27-gemini-thumbnail-playbook-audit.md` §3 + §6 item #4) 建議加 20-30 張 Taiwan/HK 健康創作者 baseline corpus 補「Magazine Cover aesthetic」「Calm Expert persona」等 cultural-fit 缺口，修修明確 veto。

**Why**: 修修頻道的 positioning 策略是 **Western YouTube 視覺語言 + zh-Hant 語言** 當差異化武器。在中文 wellness feed 裡看起來 foreign / out-of-touch **是刻意要的 pattern interrupt 效果**，不是 bug。融入既有中文健康創作者主流視覺反而會稀釋差異化。

**How to apply**:
- Thumbnail / title brainstorm 工作 — 永遠**只用** Western 創作者作為視覺/結構 reference（Ali Abdaal / Hormozi / Cleo Abram / Jeff Su / Attia / Huberman / Bryan Johnson / Saladino / Rhonda Patrick 這類英文 longevity / productivity / explainer creators）
- 中文語言**handling**規則保留（§5.4 modal particles 「喔/啊/啦」/【】lenticular brackets / TW vs HK 用詞 glossary / 簡轉繁 QA），這些是「怎麼用繁中寫」，不是「中文創作者長什麼樣」
- 文化框架補強（§1.4 Confucian collectivist hooks「陪伴孩子成長 / 別成為家人負擔」）可保留 — 是 audience cultural psychology，不是 creator reference
- 不要主動建議「加 Taiwan/HK creator 參考」「研究在地競品縮圖」「分析中文 wellness feed 排版」這類 work
- 鎖在 thumbnail / title brainstorm scope；若未來 修修 在其他工作中（KB / 內容研究）需要中文 reference 是另一回事
- 「目前」（修修原話）= 還沒看到實際輸出前的階段；運行幾次後修修可能會修正立場，到時再依新指令
