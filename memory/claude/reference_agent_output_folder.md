**每輪有產出物的工作，交付時在 `E:\data\AgentOutput\` 下自建
`YYYYMMDD-<做的事>\` 資料夾放成果快照**（修修 2026-07-28 原話：「自己創一個
符合你現在在做事情的 folder，前面放上時間戳記」）。

## How to apply

- 資料夾名：日期戳 + kebab 描述，如 `20260728-thumbnail-design-v1`
- 內容 = 修修要看/要用的最終檔（圖、報告、對比組），不是中間產物
- 附 `README.md`：內容清單 + **正式落點**（vault SoT / working set / repo）+ 重出方式
- 這是**快照**不是 SoT — 正式落點照各 pipeline 規則不變（如 packaging 的
  vault `Attachments/packaging/` 雙落點）

首例：`E:\data\AgentOutput\20260728-thumbnail-design-v1\`（封面設計系統 M1 三張
+ 舊版對比 + cutouts）。
